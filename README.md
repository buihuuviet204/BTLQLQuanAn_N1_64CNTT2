# 🍽️ Restaurant Management App

A comprehensive restaurant management system built using Java and Firebase, designed to streamline operations such as menu handling, order tracking, and user role management.

## 🚀 Features

- 🔐 **User Authentication**: Secure login system with Firebase Authentication.
- 📋 **Menu Management**: Add, update, and delete food items with real-time sync.
- 🧾 **Order Tracking**: Monitor and update order status dynamically.
- 👥 **Role-Based Access**: Separate views and permissions for Admin, Staff, and Customers.
- 📊 **Sales Reporting**: Generate daily and monthly revenue reports.
- 📦 **Inventory Control** *(optional)*: Track ingredient stock levels.

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| Java       | Core application logic and UI |
| Firebase   | Backend services (Auth, Database, Storage) |
| XML        | UI layout (if Android-based) |
| Firestore / Realtime DB | Data storage and sync |
